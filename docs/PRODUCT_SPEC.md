# 八百万図AIツールボックス AIスライドスキル

2026-10-15改訂。原典スキルの効果、入力と出力、実作例での適用、使い方を結ぶ日本語サイト。

## 一覧

主役はスキルの機能。改善したいことを6分類から選び、検索・形式・特徴タグで絞る。分類は `data/skill-needs.json` の明示データを使い、単語の偶然一致で決めない。

各カードは機能名、どう変わるか、渡すもの、受け取るもの、作例で確かめる箇所、使い方と取得の順に示す。スライド画像は機能の証拠として置く。記録されたページ画像がなければ、表紙をそのページ画像と偽らない。未合格の原典検査は作例の近くに表示する。

## 詳細と再利用

困っている状況→スキルがすること→入力と完成物→この作例で使った機能→見るページ→自分の資料へ、の順にする。固定コミットの原典SKILL、利用条件、必須環境、制約を読める。原典の能力と今回実施した範囲を分ける。

日本語スキル本文を直接取得できる。単体Markdownに原典実装が内包されるように見せない。必要な一式ZIPと原典へつなぐ。依頼文フォームは原稿・読者・ページ数・書体を画面内で組み立て、外部へ送信しない。論文・画像・PPTXなど原典の必須入力をメモで代用できるように案内しない。

## プレイヤー

指定したページ・段階を直接開き、スキルの指示と見る箇所を併記する。前後・再生・ページ指定・閉じるをキーボードとタッチで使える。Web作例は元runtimeの演出を再生し、PPTXは実ファイルからの描画を表示する。編集できる範囲は画像からの推測と分け、完成物と制作ソースを案内する。通常の枚数と場面内の段階を合算しない。

## 書体

公式配布30ファミリー・45ファイル、15の組み合わせを用意する。日本語対応・種類・用途・名称で探し、実見本、用途別4ZIP、個別ZIP、公式配布先、原文OFLへ進める。外部CDNは使わず必要な書体だけ読み込む。原配布物を改変せず固定コミットとSHA-256を記録する。欧文・等幅書体には日本語の組み合わせを案内する。

## 品質と状態

原典の効果説明35点、作例での活用35点、実スライドと利用体験30点。Kimi K3とClaude Opus 5.5による同一版の独立評価を両者100点まで続ける。範囲・未確認・実行モデルを記録し、採点のために範囲や基準を緩めない。[評価条件](SKILL_EFFECT_REVIEW.md)を参照。

393px幅とPCで、横溢れ、文字の重なり、出典・取得・依頼の操作を確認する。原典の必須生成・検査と実スライドの視覚確認を区別する。生成済み・QA済み・独立評価中・ユーザー採用を同じ意味で表示しない。
