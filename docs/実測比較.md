# 原作者による実測比較

本ページは、原作者による実測検証レポートの日本語訳です。日本語版の管理者が各ツールを再検証した結果ではありません。

原作者は2026年10月7日、同一の指示を31件のスキルに渡し、隔離された使い捨て環境にてClaude Code（Claude Opus 5.5）上で実行検証を行いました。そのうち27件から成果物が得られています。

編集可能性（PEI）はSlidesGen-Benchを参考に、出力されたファイル構造から判定されています。内容評価はPresentBenchを参考にした項目別達成度評価であり、原版の記述によるとgpt-6-astraによる3回の検証および人手による確認が実施されています。

掲載順位は、納品前の手動修正量、編集可能性、内容評価の優先順で決定されています。なお、実行時間、スター数、評価ステータスは検証当時の環境・条件における記録です。

## 表の読み方

- **納品前の修正量**：原作者が、成果物を渡せる状態にするために必要と判断した修正量。
- **編集可能性（PEI）**：出力ファイルについて原版が示す編集可能性の区分。L0は編集不可、L1は文字、L2は図形、L3は構造化された要素、L5はWeb資料としての編集やアニメーションを含む結果として表記されています。
- **内容評価**：依頼に含まれる評価項目を満たした割合。100%でも見た目や編集のしやすさまで同じとは限りません。
- **時間**：原版の実行条件での所要時間。現在の環境での速度を約束する値ではありません。

基準の参考資料：[SlidesGen-Bench](https://arxiv.org/abs/2601.09487)、[PresentBench](https://arxiv.org/abs/2603.07244)。

| [NanoBanana-PPT-Skills](https://github.com/op7418/NanoBanana-PPT-Skills) | Google Geminiの画像生成用APIキーが必要だったため、実行を試みていない。 |

| [MultiAgentPPT](https://github.com/johnson7788/MultiAgentPPT) | 独立したWebアプリで、各エージェントにLLMのAPIキーが必要。Claude Code用スキルとしては実行できなかった。 |
