# 現行方針：日本語で、いいスライドを作りきる

2026-10-14更新。ユーザーの最新指示で、209件全件制作と大規模検査を中心とした旧方針を変更する。

## 目標

Studio Yebisu独自のAIスライドサイトとして、原典GitHubスキルを実際に使った魅力的な日本語資料を増やす。完成スライドをすぐ再生し、気に入った作風の日本語スキル本文を直接取得し、OSSフォントと依頼文を使って自分の題材で制作できる状態にする。

209件は出発点の資料。全件の制作・阻害条件調査・掲載維持を義務にしない。現行の厳選集は `data/product-collection.json`。原カタログ、既存制作物、原作者と条件は保存する。

## 制作方針

- Sol 6.1の並列制作を中心とする。Astraは使わない。
- 親は方針、サイト、フォント、ダウンロード、統合。子は作例・入力・短い使い方を完成させる。
- 原典SKILL、固有テンプレート、controller、生成器を適用。日本語の書体・改行・コピー・図形・演出を改良し、改変を記す。
- 大胆な文字、図形、誌面の余白、図解、短い動きを使う。同じ淡色の業務テンプレートへ揃えない。
- OSS書体を原配布物と条件付きで揃え、見出し・本文・英数字の組み合わせをAIへ渡せるようにする。

## 必要な確認だけ

生成成功と主な完成ファイルの初回表示を確認し、明白な欠けやリンク切れを直す。原典ビルドに含まれる確認は実行する。全ページ詳細目視、独立採点、構造監査、完全ZIP再実行を必須にしない。問題がなければ再検査しない。

生成と確認は分けて記録する。過去の大規模QAは履歴として残し、今後の要件へ広げない。

## この改修の完了範囲

1. 新しい目的・製品仕様・制作方針。
2. Sol 6.1による原典方式の日本語新作2冊以上。
3. 作風と完成スライドから選べる厳選一覧とフロートプレイヤー。
4. 日本語スキル本文の直接取得、必要な一式ZIP、GitHubへの導線。
5. OSS日本語・英数字書体とAI向けのデザイン指示。

原典・素材・書体の条件と帰属を保持する。公開更新・main merge・deployはローカル制作とは別に扱う。
