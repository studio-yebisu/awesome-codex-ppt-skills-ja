# 日本語AIスライド制作スキル集：現行方針

現行の製品仕様は [PRODUCT_SPEC.md](PRODUCT_SPEC.md)。2026-10-13のユーザー再訂正とAstraによる意図整理を反映する。

209件・6カテゴリを保持し、実在スキルをこの環境で使って日本語の業務・発表資料を制作する。利用者が実例を閲覧し、成果物を持ち帰り、日本語依頼文と派生スキルで自分の制作へ進めるコレクションにする。

## 正本と初回範囲

- data/skills.json：原典209件と分類・作者・原典の対応。
- data/case-inputs.json：架空サンプル5題材の入力。同じカフェ題材をPPTX/Webで共有する。
- data/project-workflows.json：209件と現行作品・日本語派生の対応。
- data/case-studies.json：今回の制作事例と閲覧・配布・原典・検証への対応。実数と実施状態をここから表示する。
- examples/cases/：初回6冊45枚の入力、制作ソース、成果物、制作・検証記録。
- skill-forks/：個別条件を保持した3日本語派生。日本語入力・組版・再制作・検証を再利用できる形にする。

6冊・3派生は初回範囲。全209件の実制作・条件確認・互換性確認が完了したとは扱わない。完了の記載は実際の記録とQAに基づいて更新する。受入条件は [PRODUCT_SPEC.md](PRODUCT_SPEC.md)。

## 退役した改修案

独立5スキル・共通rendererの6デッキへの置換は不採用。その後の209カード＋自己紹介題材の3冊12枚もユーザーの意図を満たさず、今回の完成成果へ算入しない。

旧data/actual-examples.json、examples/actual/、旧QAの完了表示はその試作の記録。技術部品を再利用できるが、現行製品の完成・採用の根拠にしない。

## 品質・条件・公開

上流の実手順・実装・テンプレートで制作し、共通rendererへの置換を該当スキルの実例と呼ばない。PPTX入力SVGとPowerPoint本体で描画した出力を区別。HTMLの表示・編集・オフライン・印刷は実施したものだけ記録する。

一覧編集のCC0と個別コード・素材・書体の条件を分ける。原作者への帰属、MIT／AGPL等の条件、対応ソースを保持する。日本語版を原作者の公式配布と名乗らない。

ローカル実装、技術QA、人の採用判断、外部公開は別の状態。既存リポジトリ名とGitHub Pages URLを維持し、公開更新・main mergeはユーザー指示に従う。今回の完了は外部公開を含まない。
