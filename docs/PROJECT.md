# YEBISU SLIDE STUDIO

Studio Yebisuが企画・編集・制作する、日本語のAIスライド制作プロジェクト。
209件の翻訳カタログを出発点に、実際に使える派生スキルとオリジナル作例を開発する。
元カタログは検索資料として残し、トップは作例・制作方法・フォントから選べる構成にする。

## 品質と帰属

日本語のタイトル、自然な改行、禁則処理、数字と単位、出典、発表用サイズを重視する。
「完璧」「最強」は開発方針であり、検証していない品質・互換性を断言する表示には使わない。
本プロジェクトの独自部分はCC0を維持し、派生スキルは元のMIT / AGPLを継承する。
自作デッキは上流スキルの公式作例と混同させず、使用した制作系を記録する。
