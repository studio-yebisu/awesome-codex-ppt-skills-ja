GET STARTED

作例から、自分の資料へ。

サンプルで構成と見た目を確かめたら、同じスキルで自分の原稿を形にします。

1. 好きな作例を選ぶ

ギャラリーで作例を開くと、左右キーでページ移動、再生・停止、講稿、プロンプトのコピーが使えます。「制作ソース」にはJSON、SVG、単独HTML、講稿、制作プロンプトが入っています。

PowerPointで修正するならPPTX、ブラウザで発表するならHTML。SVG / HTMLの出現演出は、PPTXの静止版に含めていません。作例PPTXの文字・図形・線はネイティブ要素。店舗企画にはデータ付きのネイティブchartを収録しています。

2. スキルを入れる

共通制作スキルか用途別の派生版をダウンロードして展開。SKILL.md、参照文書、実行CLI、入力例、LICENSEが入っています。

  • Codex：通常は ~/.codex/skills/。CODEX_HOMEを指定している環境ではその skills/ にフォルダごと置く。
  • Claude Code：通常は ~/.claude/skills/。プロジェクト限定なら .claude/skills/ に置く。
  • スキル機能がないエージェントでも、SKILL.mdの場所を指定して読んでもらうか、CLIを直接使える。

導入先は利用環境の設定に合わせてください。元のライセンスを含めて保存してください。

3. 日本語で依頼する

yebisu-japanese-slidesを使って、社内向けに
「週次レポートへのAI導入」のスライドを4枚作って。
Noto Sans JP、16:9、落ち着いた青。
結論 → 分担 → 試行計画 → 判断基準の順で。
SVG・再生HTMLと講稿を付けて、数値は架空と明示して。

入力JSONを制作し、同梱rendererでSVGとHTMLを生成できます。Node.js 22以上を推奨。SVG / HTML生成は追加ライブラリやAPIキー不要です。

node "/path/to/skill/scripts/render-deck.mjs" "/path/to/deck.json" "/path/to/new-output"

まず試すなら入力に同梱の assets/example.json を指定。既存フォルダは上書きせず、新しい出力先を使います。

編集可能PPTXも出す

各パッケージにはPptxGenJS用の簡易exporterも同梱。スキルフォルダで依存を入れてから使います。

npm install --ignore-scripts
node scripts/export-pptx.mjs assets/example.json new-deck.pptx

簡易CLIの文字・四角・円・線はネイティブ要素。自由形状pathはSVG画像となり、PowerPointのポイント編集には対応しません。既存PPTXの編集、データ付きchart、tableも簡易CLIでは対応していません。今回の作例PPTXは別の制作系で作成しています。

日本語を読みやすくするコツ

  • 見出しは短く、ひと目で何のページかわかる言葉に。
  • 1280×720なら見出し48–72px、本文26–36px程度から。文字が多いときはページを分ける。
  • 句読点や閉じ括弧を行頭に置かない。数字と単位、固有名詞は途中で切らない。
  • Noto Sans JPは汎用、BIZ UDPGothicは教材・業務、Noto Serif JPは表紙・企画に。
  • 出典、図表の単位、架空データの表示を残す。講稿と画面の情報を分ける。

書体の出典と配布条件。新しい資料には正規のフルフォントを用意してください。
