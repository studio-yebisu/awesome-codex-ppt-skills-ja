# Reference Cases

This asset folder stores lightweight indexes for reference decks. Do not copy large source PPTX files here. Keep source paths pointing to `_reference_skills/ppt` or user-provided run inputs.

Chinese gallery files:

- `chinese-gallery/case_inventory.md`
- `chinese-gallery/case_index.json`

The gallery helps the skill learn Chinese PPT typography, style, structure, placeholder usage, and layout patterns. It does not limit what users can ask the skill to create.
