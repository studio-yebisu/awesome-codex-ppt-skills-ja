# 图片重建与元素拆分

目标：用户能选择、移动、替换和修改需要操作的每一个语义元素。
不是逐像素分解，也不保证还原源文件中已经丢失的结构。

## Page Spec 优先

由本技能 Step 2 生成的页面必须先读取 `page-spec.json`：其中已确认的文字、数据、来源、元素 ID 和原生/图片意图是语义事实，不得通过 OCR 重新猜测或静默覆盖。页面图片负责补充视觉位置、样式、层级和遮挡。

只有用户直接提供现有页面图片/PDF、没有 Page Spec 时，才从图像识别可见内容并创建 Page Spec。低置信度文字和数据仍需记录为待确认项；用户要求“保持原内容”不等于授权虚构看不清的内容。

## 输入归一化

1. 原图留存 sources/；单页图片按自然页序编号。
2. PDF 先渲染成逐页图片并记录 PDF 页码；多个幻灯片拼图先切成独立页。
3. 拍摄图片先处理透视/旋转，再识别坐标；原始文件和校正文件都保留。
4. 用实际像素尺寸作为 scene.canvas。EXIF 旋转后的尺寸是坐标基准。
5. 不从像素猜测原母版、动画、隐藏内容、备注或图表数据源。

## 识别清单

Agent 结合 Page Spec 与页面图片（直接还原任务可辅以 OCR），对每页列出：
- 稳定 ID、元素类别、像素 bbox、前后遮挡关系；
- 可见文字逐字转录、字号/字体候选、颜色和对齐；
- 表格单元格、可验证图表数值与单位；
- 图片内容、独立移动需求、边界和分离方式；
- 来源、置信度、无法读取的部分。

`page-spec.json` 保存确认后的语义元素，`scene.json` 保存最终导出对象，`deck-spec.md` 记录门禁和未解决元素。
小字、数据和品牌标记需要局部放大核验。OCR 低置信度只是一条线索，不能自动补成看似合理的文字。
没有可靠数值的复杂图表可暂存独立原图裁片，注明不可改数据；不要虚构数值来制造原生图表。

## 重建分类

| 类别 | 优先实现 | 编辑能力 |
|---|---|---|
| 标题、正文、数字、图注 | text | 文字、字体、颜色、位置 |
| 矩形、圆、线、箭头 | shape / line | 几何、填充、边框 |
| 流程与组织结构 | group 包含形状、标签和连线 | 取消组合逐项修改 |
| 表格 | table | 原生单元格编辑 |
| 可核验的数据图 | chart | 原生图表及内嵌数据工作簿 |
| 照片、人物、复杂插画 | 独立 image | 移动、缩放、裁剪、替换；内部像素不原生化 |
| 复杂不可核验区域 | 独立 image + note | 清楚说明限制，继续处理其余可恢复内容 |

所有需要编辑的文字从底图移除，包括图例、脚注、页码。
长段落按自然段或文本块拆分，避免为了对象数将每个字拆成一件。

## 干净背景与遮挡

先制定完整层次：背景 → 后方主体 → 前方主体/特效 → 标签及信息层（以真实遮挡为准）。
凡需要单独移动的对象，都不能继续出现在背景里。
参考编辑生成清理后的背景；纯色背景可直接用幻灯片背景色。
若对象相互遮挡，分别从原始参考提取/重建对象与被遮挡背景，记录哪些像素由 AI 补全。
标志、准确数据、身份细节优先采用用户原始素材；不可验证的重建不得当成精确复原。

## 统一坐标

每张参考编辑图保持同一原始画布和位置。若获得全画布 RGBA：
- 插入时保持原画布比例和坐标；
- 或裁剪到记录的 bbox，并按裁剪后的真实 bbox 放置；
- 不得自动 trim 后仍使用裁剪前的坐标。
重叠主体分开处理。无重叠素材可生成一张素材表，再逐件裁剪。
每个可操作对象最终仍有自己的图片形状与 ID。

## 确定性裁剪工具

`extract_assets.py` 接受识别完成后的规格，不会识别元素、抠图或补全背景。
遮罩由用户/可用分割工具提供，全图尺寸、灰度：白保留、黑透明（与某些生图 API 的编辑遮罩语义不同）。
工具会保留原 alpha，与遮罩相乘；不会用颜色键删除与背景同色的主体。

```json
{
  "source": "sources/slide-01.png",
  "regions": [
    {"id": "subject", "box": [700, 180, 400, 500], "mask": "masks/subject.png"},
    {"id": "photo", "box": [80, 300, 500, 280]}
  ]
}
```

```sh
python "<skill-dir>/scripts/extract_assets.py" "<work>/extract.json" "<work>/assets/slide-01"
```

输出独立 PNG 和 assets.json（来源、哈希、实际裁剪坐标、透明度）。
已有输出时拒绝覆盖，使用新的目录。矩形裁片若含其他元素，先清理或分层，不可直接当成合格素材。

## 合成检查

场景编译后渲染 PPTX，与原图并排检查。重点观察：
- 移动文字/主体后是否露出原图残影；
- 透明边缘、阴影、光晕是否正确；
- 文字框是否被图片挡住；组合内元素顺序是否正确；
- 字体替代、自动换行、表格尺寸、图表标签是否改变版面。

`audit_editability.py` 能发现已声明的原图被当成底图、缺失/错型对象和内容差异，
但不能证明截图中没有遗漏区域，也不能自动判断遮挡补全是否可信。
