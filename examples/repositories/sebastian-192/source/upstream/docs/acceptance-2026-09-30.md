# SlideMuse 2.8.0 验证记录

本轮以已确认的8页城市出行公报 PPT 实测问题为输入，保留图片优先流程、内容自检/确认与四套风格选择。

## 实现与行为检查

- 数值/来源、标签/单位、图表尺度/几何（表格为行列对应）分别核验；v1.2 评分不会因为总状态写了 pass 而绕过待检查或失败分项。
- 无图表的文字页也核对数据视觉清单；记录多出的趋势图时评分失败。脚本核验观察记录，不能自行发现图中所有虚构内容。
- 零基线单系列条形/柱状图的像素观察核对拒绝错误长度、方向、原点、非有限坐标、缺失记录和陈旧图片/规格哈希。构造坐标不充当独立观察。
- 精确水平条形区域输出只修改指定矩形；回归核对矩形外 RGBA 像素及原文件哈希不变。过期原图、区域越界、轴裁切数值、文字溢出和覆盖原图被拒绝。
- 原生图表设置从 Scene 编译后重新读取核验；修改负值数据点反色或环形孔径会被审查发现。无需本轮过去使用的临时样式后处理。

## 实际产物回归

同一份已批准 Page Spec 和8页图片在独立验证目录复用。新 Scene 直接编译、对象审查与 PowerPoint 实际渲染；没有调用临时图表后处理或重新生图。查看整套源图/渲染对照，并完整查看第3、4页，负值条形颜色、标签空间、零轴与方向正确。字体、部分换行/表格对齐及几何图标仍为近似还原，不宣称逐像素一致。

61个已知语义元素的原生文字/数据核对无遗漏；图片版和可编辑版的新 v1.2 评分均 pass。原图条形端点从实际平色像素测量、轴锚点对照看图记录；几何核对通过。保持来源标签不变、仅故意记录错误条长/负值方向的负向对照被拒绝。

论文《Attention Is All You Need》和长篇“人工智能+”政策材料另做内容阶段人工语义复核，检查方法解释、任务/指标边界、源文冲突、政策目标与实际结果的区别。两者未进入风格和生图，不属于跨材料整套视觉测试或独立盲测；没有产生新的生图费用。
