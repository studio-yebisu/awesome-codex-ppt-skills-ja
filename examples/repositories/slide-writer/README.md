# 朝会は、判断と相談の入口に

FeeiCN/slide-writerの原典template、branding、inline、smokeと固有MiniSlidePresentationを使った日本語8枚。自作ブランドしおりのテーマを加えた日本語派生です。原典14企業テーマは今回未試行。

`python -m pip install -r source/requirements.txt` → `python source/build_slide_writer_repository_example.py --input input/data.json`。原典smokeにGit Bashが必要。単一HTMLは日本語書体とCSS/JS/自作logoを埋め込み、必要なライセンス原文を非表示JSONへ保持。原稿・HTML本文・テーマはinput/data.jsonで調整し、全ページを再確認します。
