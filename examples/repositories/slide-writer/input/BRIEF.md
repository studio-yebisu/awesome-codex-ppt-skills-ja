# 朝会は、判断と相談の入口に

読み手：小さなチームの運営担当。目的：明日の朝会で議題の分類と順番を試す。架空ブランドの独自緑テーマ。原典Mode A1で原稿を圧縮し8枚へ構成する。

## 元の原稿

しおりは架空の小さな制作チームです。朝会では昨日の作業を長く話す人と、今日どこで判断が必要かを知りたい人が混在し、相談がその場で始まって全員が待つことがあります。これはこの資料の課題仮説で、実在組織の調査結果ではありません。
提案は、議題を報告・判断・相談の三つに分けることです。進捗の報告は短いメモへ書き、会議では今日決めることを先に話します。相談は相手と次の行動を決め、詳しい話は必要な人だけで続けます。日次の記録には決めたことと次の一手を書きます。
進め方は準備、判断、相談、記録の順です。準備では議題を共有します。判断では担当が必要な選択を示します。相談では何が止まっているかと相談先を確認します。記録では担当と次の行動を残します。報告の短文化は、細部を隠すことではなく、必要な人が後で読める場所へ移すことです。
見積書のレビューという架空例では、昨日の作業一覧を順に読み上げる代わりに、今日必要な判断を先に述べます。「見積の前提を確認したい。条件の抜けがないかをレビュー担当へ相談する。確認後に見積を確定する」という説明にします。この例に実在の顧客名や実測の成果はありません。
試行は二週間という提案です。最初に議題の分類と記録の型を決め、実施中は相談を会議の外へ引き継げたかを残します。最後に判断のしやすさと記録の負担を振り返り、続けるかを決めます。時間短縮や満足度の改善は、この資料では数値を作りません。まず明日の一回で新しい順番を試すことを、最後の行動にします。
