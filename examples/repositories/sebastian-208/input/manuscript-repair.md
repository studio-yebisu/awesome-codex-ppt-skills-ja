# 雨の図書室：空間デザイン研究の提案原稿

## この原稿の位置づけ

架空の研究構想を説明する報告原稿。既存作例の構想とコピーを修復時に文章へまとめたもので、初回生成より前から存在した論文ではない。所在地、事業主体、学校、著者名、指導教員、寸法、費用、人数、実験結果は設定しない。外部論文や実測資料を引用せず、効果の検証は未実施である。

## 1. 研究の問い

雨を避ける場所に、雨を観察できる場所を重ねる。雨の日に立ち止まる理由として、雨宿り、観察、記録を組み合わせる案を考える。観察の仕掛けが立ち止まり方を変えるかもしれない、という仮説であり、因果関係や効果を示した結果ではない。

## 2. 空間の構成案

小さな空間を庇、席、棚の三つの役割で考える。庇は雨粒を受ける場所、席は庇に触れる雨の音を聞く場所、棚は観察したことを記録して置く場所である。別々の設備を増やすより、一体の空間として構想する。図は寸法や施工条件を定める前の概念図であり、排水、構造、アクセシビリティ等の検証を済ませた設計ではない。

## 3. 想定する体験

利用行為の例は、雨粒の動きを見る、庇に触れる音を聞く、気づきを短く残す、の三つである。想定する体験の一例であり、被験者の観察記録や調査結果ではない。架空の記録用紙は表現例として示す。

## 4. 検証の計画

模型を試作し、使われ方を観察し、気づきをもとに見直す、という計画を置く。何を見るかを先に決める。これは実施前の検証計画であり、比較対象、尺度、参加者数、実施日程はまだ設定していない。確定していない数値や改善率を図表へ追加しない。

表紙と目次の後、視点03–04、空間05–06、体験07–08、検証09–10の順に説明し、11頁を質疑・対話専用とする。これは発表ページの番号で、測定値ではない。学校や著者等の情報は省き、最後は設置条件や懸念を含めた対話へつなぐ。
