# 一次資料を読んだ根拠

[NumPy公式 numpy.linalg.lstsq](https://numpy.org/doc/stable/reference/generated/numpy.linalg.lstsq.html)（2026-10-14閲覧、v2.5 manual）。係数行列と右辺を受け取り、残差のEuclidean 2-normを最小にする解を返す定義、返値solution/residuals/rank/singular values、および直線y=mx+cへの当てはめ例を確認した。長い直接引用は使わず、実計算の方法と式の説明に使用。references.bibへURLを保存。

[Quarto公式取得ページ](https://quarto.org/docs/download/)と[固定1.9.38公式release](https://github.com/quarto-dev/quarto-cli/releases/tag/v1.9.38)を確認。GitHub公式release APIのWindows ZIP digestと実download SHA256が一致。原典extensionのQuarto>=1.4を満たす。最新版という主張はしない。
