# 待つ時間にも、道しるべを。

## 1. 待つ時間にも、道しるべを。

架空のファイル読込画面の設計提案。効果測定や実装済み製品の報告ではない。

## 2. 待つ人に伝えるのは、三つだけ。

何をしているか、次に何が起きるか、待つ人が何を選べるか。画面から短く答える。

## 3. 終わった作業と、次の作業を並べる。

この三工程は企画の説明例。実装は処理の完了イベントから状態を決める。

## 4. 進捗が分からないときは、状態を伝える。

実際の処理割合が不明な場合の表示案。時刻やパーセントの数字を作らない。

## 5. 失敗したあとにも、進む道を残す。

再試行・選び直し・中止の行動案。データ保持や再開が実装されているとは仮定しない。

## 6. 待つ人が、次を選べる画面へ。

まず一つの読込画面の言葉を、自分の工程と利用者の選択へ置き換える。
