# 文字のかたちを、観察する。

読者: 和文スライドを初めて作る人。実際の字体を見比べる短い観察教材。
これは自作の説明・選択例です。読了率、学習効果、可読性の実測はありません。

1. 文字のかたちを、観察する。
   同じ言葉を、違う声で見てみる。字を選ぶ前に、まずは「かたち」を見る。
   大きい「あ」の線の終わりと字の内側へ手描き線で視線を向ける。
2. 丸さは、線の終わりに出る。
   Zen Maru Gothic BoldとBIZ UDPGothic Boldで同じ「あいうえお」を並べる。
   同じサイズで線の終端と曲線のつながりを見る。印象の正解を決める比較ではない。
3. 太さを変えると、白いすき間も変わる。
   BIZ UDPGothic Regular/Boldの「雨のち晴れ」を同じ大きさで並べる。
   線の太さだけでなく字の中の白いところを見る。
4. 文字のまわりにも、居場所を。
   同じ「ひと息、どうぞ。」と同じ文字サイズで、囲みまでの距離を変える。
   文字と余白をひとまとまりとして観察する。
5. 改行は、意味の切れ目で。
   元の一文: 今日の帰り道に、花を一本。
   比較A: 今日の帰り／道に、花を／一本。
   比較B: 今日の帰り道に、／花を一本。
   声に出して「帰り道」と「花を一本」のつながりを確かめる。
6. 伝える声に、書体を合わせる。
   選択案: やさしく招く「どうぞ、ゆっくり。」はZen Maru Gothic。
   選択案: はっきり案内する「次は、ここです。」はBIZ UDPGothic。
   字を変えたら余白と改行も見る。最後はその言葉を声に出してみる。
