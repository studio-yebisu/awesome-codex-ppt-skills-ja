# 紙と、インクの休日。

独自の架空ブランド。「急いで完成させる」より、文字と紙をゆっくり眺める休日の印刷室。
既存の店、印刷所、機器メーカーや団体のブランドではありません。文字だけの名札を使い、ロゴ・商標・外部写真は使いません。

色は正確に固定する。

- 紙: #f6f0e5。主となる背景。
- 黒: #20201e。文字、黒いsplit panel、図の輪郭。
- 赤: #e52b25。細い罫線と選んだ文字の小さな目印。全面の背景にしない。
- 罫線: #d5cec2。余白を区切る薄い線。
- 補足: #66625a。紙上の小さな本文・メモ。
- 黒い面の文字: #fffaf1。

使用比率の目安は紙色70%、黒28%、赤2%。これは画面構成を決める目標で、測定結果ではない。

字体: Shippori Mincho Regularの大見出しと引用、BIZ UDPGothic Regular/Boldの本文・ラベル、Space Groteskの小さい英数字。すべて既存公式固定Google Fonts配布/OFL。

版式: 原典のtitle/wordmark、dark-left/light-right split panel、approach rowsの3段階、dark large quote、feature bar、余白の多いclose。角丸カードを繰り返さない。絵は活字・紙・ローラーの自作SVG説明図のみ。
