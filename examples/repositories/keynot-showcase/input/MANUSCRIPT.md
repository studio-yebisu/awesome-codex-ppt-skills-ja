# 紙と、インクの休日。

架空の活版印刷ワークショップ企画。日時・会場・費用・参加人数は未定。
これは体験を説明する構成案です。実施実績、制作操作や安全手順、安全性能の実証を発明しません。

1. 紙と、インクの休日。
   ひと文字を選んで、自分の一枚にする。
2. ひと文字から、はじまる。
   形を見て、使いたい言葉を選ぶ。
   線のかたち: 細いところ、太いところを見比べる。
   字の中の余白: 白いすき間まで、文字の一部として見る。
   残したい言葉: ひとことから、紙に置く言葉を考える。
3. 選ぶ。並べる。刷る。
   文字を選ぶ: 残したい言葉と字のかたちを見比べる。
   紙に並べる: 言葉のまとまりと周囲の余白を眺める。
   一枚を刷る: 紙に残った文字と刷り跡を見てみる。
   数字01–03は体験案の順序。人数・時間・回数の実績ではない。
4. 余白も、刷らない場所のかたち。
   同じ言葉でも、紙の中の居場所を変えてみる。
5. 紙とインクを、見比べる。
   同じ文字を、紙と刷り跡の両方から眺める。
   紙: 紙面の色と手触りを見比べる。
   インク: 文字の表情をインクの側から見る。
6. 持ち帰るのは、自分の一枚。
   どんな言葉を紙に残したい？
