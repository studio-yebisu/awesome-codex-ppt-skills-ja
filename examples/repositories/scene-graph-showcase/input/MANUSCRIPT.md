# 遠くの席へ、伝わる資料。

会場で読む資料の構成を提案する、説明用の自作教材6枚。
距離による可読性改善・理解度・最適なpt値を測定した結果ではない。

1. 遠くの席へ、伝わる資料。
   会場で読む資料の、構成案。
2. 一頁に、一つの問い。
   見出しと主題を分けず、頁の一つの役目を決める。
3. 見出しは、ひと息で。
   「読み方の検討を行う」から「まず、読み方を決める」への短い言い換え例。
4. 強い文字を、少なく。
   見出しを太く、本文を軽く。目立たせる言葉と他の説明の役割を分ける。
5. 色には、役割を。
   原典projectionの見出しは紺、本文は濃い灰色。元の枠が話の区切りを示す。
6. 最後に、何を残す？
   Q&A / 次に直す、一つの場所。
