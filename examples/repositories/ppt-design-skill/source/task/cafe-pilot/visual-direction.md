# Visual Direction

候補professionalは業務帳票寄り、vibrant-startupは彩度が高い。warm-elegantは近いが、試行を落ち着いて読む紙面にはterracottaの暖色とserif-editorialの見出しを選んだ。これはrecommend_stylesの候補そのものではなく、公開ThemeComposerの別atomsを比較して選ぶ自律判断である。

小さな地域カフェの現場共有用。terracotta / serif-editorial / accent-bar / standardを選択し、見出しをShippori Mincho、本文をBIZ UDPGothicの公式静的字体へ明示変更。暖色の紙面と大きな数字。表紙→役割→試算→記録→判断のリズム。写真は使わない。ユーザーの自律制作依頼に基づく選定であり、人間のデザイン採用は未申請。
