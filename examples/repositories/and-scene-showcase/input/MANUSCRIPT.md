# 8段階の原稿

1. 一冊の本が、次の人へ。

架空の交換本棚の提案。同じ一冊が、置く・見つける・戻すをつなぎます。

2. 読み終えた一冊を、本棚へ。

持ち主から、共通の本棚へ。一冊の位置が変わり、関係が見えてきます。

3. 本の名前と、ひとことを添える。

本の名前と短いひとことを添える、という参加の案。

4. 次の読み手が、一冊を見つける。

本棚を眺める次の読み手と、同じ一冊をつなぎます。

5. 読みたい本を、持ち帰る。

本棚の一冊が、次の読み手の側へ移ります。

6. 読み終えたら、次へつなぐ。

読み終わった一冊を、次の人へつなぐことを考えます。

7. もう一度、本棚へ。

同じ一冊を共通の本棚へ戻す。交換の輪をもう一度。

8. 一冊を、次の人へ。

本棚を介して、一冊を次の人へ。料金・住所・営業実績は未設定です。
