# CyberPPT日本語派生版のQA方針

原典: crazyykhllc-bit/CyberPPT @ 980e5576565f0673c67ee41b01d20ed66cb8417c。`upstream/` は原版を保持する。

ユーザーが依頼した「スキルをフォークして日本人向けにリファインする」範囲で、画像生成の字形をネイティブPowerPointへ置き換える際の受入条件を以下のように改訂する。原本のテスト結果を合格へ書き換えない。

| 原典 | 本派生版 |
|---|---|
| 画像blueprintとの厳密なpixel/bbox一致が次頁制作・統合の条件 | 原典比較は実行し不合格を保持。別に日本語の内容・要素対応・可読性・編集性を確認して次頁へ進む |
| 原典の固定Typography Scale | 日本語の文字幅・長い表セル・実表示に合わせた字号を採用。実字号を要素JSONに保存 |
| 各頁のuser_confirmed=true | 人間の確認を偽らずfalseのまま保持。代理制作の内部QAをagent_reviewedとして分離 |
| 最終mergeの前に原典strict gate全通過 | 全頁のPowerPoint実描画と日本語派生QAの通過後に、既に作成した単頁を統合。元のstrict未達は残す |

変えない条件: 内容の事前lock、全頁ImageGen blueprint、PptxGenJSで単頁ずつ再構築、全可視要素の対応表、PowerPoint実描画、実render側の位置・寸法記録、表や主要文字を編集可能にすること、見切れや意味の誤りの修正、原本出典・ライセンス保存、最終統合時にページを再生成しないこと。

この派生は厳密1:1再現の成功例ではない。`original_gate_not_passed` と `japanese_fork_qa` を常に区別する。画像生成が描いたカレンダーと原典アイコンライブラリのカレンダーには見た目の差があるが、予定を選ぶという意味は保持する。文字の誤り・数字の変更・要素欠落は許容しない。
