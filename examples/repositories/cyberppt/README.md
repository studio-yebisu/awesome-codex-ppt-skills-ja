# 画像案を測って編集可能な図表へ組み直す

保存したImageGen原図の主要文字・表・フローを、個別に編集できるPPTXへ戻す5頁の部分例。図の文字・条件と関係を照合し、見た目の一致と編集性を別々に検査する。

- 2頁：左のImageGen原図と右のPowerPoint描画で、SNS/Web/掲示板→一覧→各店の詳細を照合する。
- 3頁：5列×3行の日時・場所・費用・雨天条件を比べる。下部の結論と脚注には別の領域を確保。
- 4頁：担当案・確認項目と3段階の手順を比べる。
- 5頁：『探してもらう』を途中で分けず、『文字の読みやすさ・問い合わせ』を同じセルで読む。

比較画像の左はHTMLではなく、保存済みImageGen bitmap。出自と左右のhashは`review/preview-comparison-sources.json`。原図は変更していない。今回の追加修復はCodexのコード/配置修復であり、新たなOpus/画像生成は行っていない。

原典はCyberPPT @ `980e5576565f0673c67ee41b01d20ed66cb8417c`、MIT。原典の元資料分析/MBB・複数SCR案・8方向の利用者選択・段階/逐頁の利用者確認は未実施。元の依頼から全工程を完了した成功例とは扱わない。新題材の一般手順は`SKILL.md`に分離した。

現在のPPTXは主要文字90、native図形154（文字枠を含む）、画像3。画像は表紙の小アイコンのみで、Officeのデータ連動Chart/Tableは0。全5原図/全5出力と局所比較を制作側で視認し、PowerPointの文字枠90個の測定でoverflow0。

原典のpixel/bbox比較と、manifest/visual-qa/strictを全指定したvalidatorは不合格。構成署名・再構築計画・全要素の実測・容器・連続文・表の記録を整えたが、紙の明暗、字形/位置の差、過去にない利用者承認は合格にしていない。未達のコードと実結果は`review/repair-strict-receipt.json`。可読性/編集性の技術検査を原典合格へ読み替えない。

全頁の確認と配布再実行は`QA.json`、原典と派生の境界は`PROVENANCE.json`。独立再評価、利用者の採用、実施効果は未取得。再生成は`REPRODUCE.md`。`source/finalize.py`は旧カタログ生成コードであり、現版の再実行入口ではない。
