# 社内検索を4週間で試す

読者: 導入を検討する50人の架空企業の担当者。
形式: 編集可能なBento文書とreadonly再生コピー。

1. 企画: 見出しと編集可能な文書の図形で、試行の入口を示す。
2. 対象範囲: 文書と質問の組合せを絞る。
3. 権限確認: 検索候補へ絞るまでの工程を示す。
4. 根拠付き回答: 同じ検索ノードを保ったmorphで、出典付き回答へつなぐ。
5. 評価目標: 全30件中24件以上という計画値を純JSONのchartとcountUpへ割り当てる。権限20件・漏えい0件は別条件。実績ではない。
6. 着手: 整理→試作→評価→判断を4週の図形として示す。

原典の固定shellは変更しない。同じ文書IDを保持する再構築と、別文書IDによる独立コピーは区別する。字体は公式OFL由来のJP subset。countUpの初期化前に最終値が一瞬描かれる元runtimeの挙動は変更していない。
