# 原典の適用と局所修正

公式new_deck.pyでb01,b09,m05,b06,b05,m35,b10を選択。seed.htmlが生成直後、deck.htmlが文言・図表を編集した正本。

- b09：前年と当月、差分の4指標表。
- m05：共通スケールのCSS棒グラフと増収の内訳。PPTXでは独立したネイティブ矩形とテキスト。
- b06：粗利計算と未確認要因を左右へ配置。
- b05：返品理由の分類から改稿・測定へ進む矢羽。
- m35：今回の判断案と、担当者・期限・確認材料。
- b01/b10：表紙と裏表紙。原典クレジットは裏表紙のみ。

原典ソースは変更していない。converterはCSS zoom=0.8がある追加パーツの図形位置を縮小する一方、文字サイズを縮小しないため、出力PPTXの該当2枚で文字サイズ・行間だけ0.8倍へ補正。適用数はconversion-corrections.json。HTMLとPPTXのcheck_deckはFAIL0。WARNは表紙と裏表紙の副題・タイトルなし、判断ページの充填率49%と裏表紙15%。薄い情報を水増しせず役割を保持。

全7枚をPowerPoint本体でPNG/PDFへ描画し、1600×900の個別ページを目視。ブラウザ版面検査は親の既存サイト上での確認へ委ねる。元check_layout.mjsは実行していない。
