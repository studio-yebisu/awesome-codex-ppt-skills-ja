# 6枚の原稿

1. **星を待つ、夜の天文台。** 夜空を見上げる観察イベントの架空企画。日時・会場未定。
2. **みんなで、夜を見上げる。** 案内を聞く、静かに待つ、見えたものを話す。急がず過ごす。
3. **入口から、星へ。** 迎える、待つ、観察する。実施時刻と観察方法は未定。
4. **見るだけの日も、あっていい。** 見る：各自で探す、立ち止まる。話す：気になることと次に見たいものを共有。
5. **待つ時間も、企画の一部。** 当日の確認で、屋外で見上げる案と室内で話す案を選ぶ。代替会場・中止条件・連絡方法は未定。
6. **今夜の空を、次の話に。** 架空イベント案。観測実測・性能・科学データや開催実績は含まない。
