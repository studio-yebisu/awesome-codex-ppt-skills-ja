# ひとつの服を、もう一度。

1. 表紙。衣服お直しワークショップの架空企画。開催日時・会場は未定。
2. 一着と、ひとつの気がかり。洗濯した服、気になる箇所のメモ、袋を持参。会場は基本の道具・材料、案内役、作業と記録のスペースを準備。
3. 見つけて、試して、記録する。行程案は共有20分、相談20分、作業60分、記録20分。時間は仮の設定。
4. 役割を、先に分けておく。参加者は希望、案内役は続け方、記録役は持ち帰る記録を次へ渡す。
5. 持ち帰るのは、この三つ。服、変えた箇所と気づきの記録、家で続ける次の一手。未完成も記録する。
6. 直せたところも、次の一手も。持ち帰ろう。開催前の企画案、日時・会場・参加条件未定。
