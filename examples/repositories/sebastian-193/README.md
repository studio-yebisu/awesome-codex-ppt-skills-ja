# 研究資料を編集可能なPowerPointへまとめる

論文・研究メモ・図・参考テンプレートから、発表の構成と図表を作るスキルです。新しい資料の作成、既存PPTXの修正、画像から編集可能なPPTXへの復元に対応します。参考資料の書式と、研究内容が決める図表の配置を分けて考えます。

原典は [deathcats4/scholar-ppt-cn](https://github.com/deathcats4/scholar-ppt-cn/tree/6fca3dc0f0fd6033279cc1bd29467967cc185272)、固定commit `6fca3dc0f0fd6033279cc1bd29467967cc185272`、MITです。非公式の日本語ガイドです。

## 渡すものと受け取るもの

研究の元資料、読み手、発表時間、枚数、必要な出力形式を渡します。研究メモや大綱からも作れますが、実験結果や引用文献を補完させません。既存PPTXの修正ではそのファイル、画像の復元では元画像が必要です。使いたいテンプレートや書体があれば指定します。

完成物は編集可能なPPTX、各頁の確認画像、制作ソースと原典の検査記録です。画像を残す領域は、内部の文字や図形まで編集可能とは扱いません。

## 使い方

1. 元資料と目的を読み、制作・修正する範囲を決めます。内容に影響する判断が未指定なら確認します。明確な承認がある範囲は、その内容で進めます。
2. 参考テンプレートの配色・書体・見出し・注記などを整理します。以前の研究結果、著者、所属、データを新しい資料へ流用しません。
3. 入力に合う方式を選びます。画像案を作らず直接生成する、画像案を確認してから編集可能な資料へ組み直す、既存PPTXを修正する、元画像を復元する、の手順は固定原典の該当参照に従います。
4. 研究の主張・根拠・順序・比較・接続関係に合う図や表を作ります。箱とラベルを一緒に動かすならグループ化し、箱の移動に追従する線は接続先へ結び付けます。
5. 全頁を描画して読み、本文・図・数式・凡例・出典・文字欠けを直します。完成ファイルに原典の検査と最終ファイル照合を実行します。編集の確認はコピーを保存して開き直します。

## 同梱する実行例

「小さな道案内」は架空・未実施の研究計画8頁です。画像案を生成せず、日本語原稿から直接作る方式を使いました。元テンプレートのマスター・レイアウト・テーマを保持し、頁内の図は研究の意味に合わせて新しく作っています。

- 2頁：見つける→読む→方向を決める、という判断の順序。
- 3頁：同じ青い枠で、複数の行き先を並べた案と、次の判断に絞った案を比較。優劣は未検証です。
- 4頁：入口・分岐・受付と、案内の役割の対応。
- 5頁：文字・矢印・補助情報への注釈。内側の余白は寸法線で示します。
- 8頁：修正から試作へ戻る工程図。手順確認の箱と文字をPowerPointで動かし、保存・再表示しても4本の矢印が接続を保つことを確認しました。

## 必要な環境と限界

同梱例はNode.js、PptxGenJS 4.0.1、Python 3.10以上、lxml、pypdfium2、WindowsのPowerPointとPowerShell 7を使用します。BIZ UDPGothicは公式配布ファイルとOFLを同梱しています。原典は中国語学術向けで、この例では日本語とBIZ UDPGothicへ明示変更しました。

ZIPにあるのは直接生成する作例と必要な原典・検査部分です。他の方式を使う場合は、固定原典の該当する参照と実行ツールを取得してください。画像案の生成、画像からの復元、実論文の抽出、実施設での評価は、この作例では試していません。

原典の静的検査はerror0・warning0、完成PPTXの照合も実施しています。描画確認、編集確認、配布ZIPの再実行は `QA.json` に範囲を記録しています。独立再評価と利用者の採用は未完了です。具体的な再実行は [REPRODUCE.md](REPRODUCE.md) を参照してください。
