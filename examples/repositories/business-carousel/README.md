# 引き継ぎ、何を書けばいい？

原典43番の指示を使い、ブリーフと日本語6枚のHTML構成確認プレビューを制作。原典に自動レンダラーやPowerPoint出力CLIはなく、この例のソースはその指示を実行した専用の自作HTMLです。

## 使って試す

HTTPでindex.htmlを開く。←→とキーボードでページを移動。最後のボタンで3行の記入型をコピーできます。入力JSONとブランド条件を変えて再生成し、原稿と全ページを確認してください。

## 原典のどこまでか

この原典の出力は、デザイナーへ渡すブリーフとHTML構成確認プレビュー。今回も構成確認までで、Canva/Figma等での公開用仕上げ、縦長版、LinkedIn投稿PDF、人の承認、公開は未実施。数値効果・書式の普遍性を保証する例ではありません。

日本語の単語数を英語基準に機械換算せず、短い原稿、明示した記入例、実際の読みやすさで調整しました。字体は公式BIZ UDPGothicを必要文字へサブセット化し、内部名をYebisu Carousel JPへ変更。fonts/OFL.txtに原文条件を保持。原典のMITと原作者をLICENSE.upstreamに保持。
