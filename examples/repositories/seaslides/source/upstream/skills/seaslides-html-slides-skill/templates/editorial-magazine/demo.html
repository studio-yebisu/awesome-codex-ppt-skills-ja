System Design

Modular by Default

Every service is a self-contained module with its own data store, API contract, and deployment pipeline.

This architecture enables independent scaling with throughput \(\propto n\) nodes, fault isolation, and team autonomy. Each module publishes events to the shared bus, allowing downstream services to react without tight coupling.

"Modularity is not about splitting code.
It is about splitting decisions."
-- Engineering Principles, 2026

Python · Gradient Descent
import numpy as np

def gradient_descent(grad, x, lr=0.01, steps=100):
    """Return optimized parameters."""
    x = np.asarray(x, dtype=float)
    for _ in range(steps):
        g = grad(x)
        if np.linalg.norm(g) < 1e-8:
            break
        x = x - lr * g
    return x

result = gradient_descent(lambda x: 2*x + 2, [5.0])
Key Formulas

Objective: \(f(x) = x^2 + 2x + 1\)

Gradient: \(\nabla f(x) = 2x + 2\)

Update: \(\theta_{t+1} = \theta_t - \alpha \nabla_\theta \mathcal{L}(\theta_t)\)

Algorithm · Binary Search
\begin{algorithm}
\caption{Binary Search}
\begin{algorithmic}
\PROCEDURE{BinarySearch}{$A, target$}
  \STATE $lo \gets 0$, $hi \gets |A| - 1$
  \WHILE{$lo \leq hi$}
    \STATE $mid \gets \lfloor (lo + hi) / 2 \rfloor$
    \IF{$A[mid] = target$}
      \RETURN $mid$
    \ELSIF{$A[mid] < target$}
      \STATE $lo \gets mid + 1$
    \ELSE
      \STATE $hi \gets mid - 1$
    \ENDIF
  \ENDWHILE
  \RETURN $-1$
\ENDPROCEDURE
\end{algorithmic}
\end{algorithm}
Complexity Analysis

Time: \(O(\log n)\) — halves the search space each iteration.

Space: \(O(1)\) — uses only three index variables.
