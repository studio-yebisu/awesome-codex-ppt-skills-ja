# 変換依頼

既存の自作PPTX「小さな展示を、ひとつの体験に。」5枚を、lanceli93/aws-html-slides原典のPPT conversion経路で日本語の動くWebスライドへ変換してください。元extract-pptx.pyを実行し、抽出した全テキスト/画像/notes、元native OOXMLの円・四角・三角・辺のgeometryと色を保全する。原典Neon Cyberの100vh viewport CSS、controller/IntersectionObserver/nav dots/keyboard/wheel/touchとreveal animation、native SVG edge/packet choreographyをStudio Yebisuの仮想展示案へ適用。Akxan/ppt-agent-skillのHTML→native PPTXを入力として用いた出所/commit/MITも保持。AWSロゴや公式性/提携表示は使わず、派生footerへ置換し明記。日本語大見出し/短い明朝説明/英数字のOSS字体を役割別に、実TTF/OFLを同梱。HTML/SVG編集可能であり、新規PPTX生成と表示しない。必要な原典buildと代表完成物/ページ送りの初回表示だけ確認。独立レビュー/全ページ目視/構造監査/ZIP再実行なし。
