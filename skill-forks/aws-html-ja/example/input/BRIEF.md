# 変換依頼

既存の自作PPTX「小さな展示を、ひとつの体験に。」5枚を、lanceli93/aws-html-slides原典のPPT conversion経路で日本語の動くWebスライドへ変換してください。元extract-pptx.pyを実行し、抽出した全テキスト/画像/notes、元native OOXMLの円・四角・三角・辺のgeometryと色を保全する。原典Neon Cyberの100vh viewport CSS、controller/IntersectionObserver/nav dots/keyboard/wheel/touchとreveal animation、native SVG edge choreographyをStudio Yebisuの仮想展示案へ適用。Akxan/ppt-agent-skillの制作元作例を入力として用いた出所/commit/MITも保持。3枚目の番号・見出し・説明12個は出力SVGだけで対応する図形の中心へ揃え、元座標と変更内容を記録する。入力PPTXは原本保全。AWSロゴや公式性/提携表示は使わず、派生footerへ置換し明記。日本語大見出し/短い明朝説明/英数字のOSS字体を役割別に、実TTF/OFLを同梱。HTML/SVG編集可能であり、新規PPTX生成と表示しない。原典の機能と作例で実行した範囲を区別し、実画面で位置と読みやすさを確認する。Kimi K3とOpus5.5の独立評価は別記録に残し、未評価を合格扱いしない。
