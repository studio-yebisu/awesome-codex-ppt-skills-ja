# 3ページ目ラベル配置アダプタ（出力SVGのみ）

`source/layout_adapter.py`（`aws-html-showcase/page03-step-label-center/v1`）の説明です。

## 入力と出力の違い

- 入力 `input/deck.pptx` の3ページ目では、手順ラベルは各列の左寄りに置いた左揃えのテキストボックスです。PowerPointで入力を実描画しても左揃えなので、変換で揃えの指定が失われたわけではありません。
- 出力SVGでは、この12個のラベルだけを、指定した図形の横中心へ `text-anchor="middle"` で配置します。図形との対応は名前で固定しています。近い図形を自動で探す処理はありません。
- これは元の配置にない、出力側の見せ方の変更です。原典 aws-html-slides の機能ではありません。原典SKILL.mdのPPT変換の約束は、テキスト・画像・ページ順・speaker notesを保つことで、座標の変更は定めていません。

## 変えないもの

- `input/deck.pptx`、`extraction/native-shapes.json` の元の座標・揃え・文字（アダプタは読むだけで書き換えません）。
- 図形・矢印・線の位置と色。T139・T153〜T156のテキスト。1・2・4・5ページ。

## 元配置の記録

元SVGの配置（各ラベルの元x、左揃え）と出力配置の差は `source/label-alignment.diff` に記録します。このdiffは主生成器が書き出すもので、本モジュールは作りません。

## 入力の検証

`label_alignment(prs, slide, idx)` は idx 2 以外では `{}` を返します。idx 2 では次のどれかが合わなければ `LayoutAdapterError` で停止します。

- 全5枚・16:9であること。
- 3ページ目の28個の shape 名・順序。
- 対象図形の種類（ellipse / rect / custGeom）、塗り色、bbox。
- 12ラベルの文字・bbox・書体・文字サイズ。
- `algn` が未指定か `l` であること。

`audit_document(prs)` は適用範囲と12件の対応表をJSON形式で返します。点数は付けません。

## 確認していないこと

このモジュールは入力の値を照合するだけです。ブラウザでの表示確認と全ページの目視確認はしていません。画面の確認は親作業で行います。
