# 音を、地図にする。 内容設計

架空の文化イベント企画。学術研究、実測値、実在する街のデータではない。

1. cover / dark: 音を、地図にする。副題「街を歩き、聞こえたことを持ち帰る。」右側に架空地図を置く。地図は会場に貼る記録例の説明図。
2. statement / light: 同じ道でも、聞こえ方は違う。大きな「30」分は企画上の歩行時間、集計や結果ではない。歩く範囲と立ち止まる場所を自分で選び、印象の違いを楽しむ。
3. flow / dark: 聞いたことを、三つの欄に残す。01場所（ざっくり）02音の種類03その場の印象。録音は不要、文字で記録。個人の住所・会話は書かない。
4. data-split / light: 音の種類と、印象を並べる。架空の橋/路地/広場の3例。水音「ゆったり」、足音「こつこつ」、風「ひらける」。右に巨大な01と波形的図。波形は抽象記号で実測/再生データではない。
5. image-split / dark: 持ち帰った記録を、壁の地図へ。架空会場地図に記録札を置く展示説明図。一つの音に決まった意味を付けず、参加者の言葉を読む。音源未収録で再生機能なし。
6. bullets / light: 安心して歩ける、余白をつくる。歩く/会場で読むを選ぶ。私有地に入らない。車道で立ち止まらない。会話や住所を書かない。展示参加は別に選び、外したい札は外す。
7. closing / dark: 次の角で、ひとつ聞いてみる。企画案「受付5分・散歩30分・共有15分」。参加人数/成果の実績なし。最初の試行では歩行ルート・記録負担・展示を確認する。
