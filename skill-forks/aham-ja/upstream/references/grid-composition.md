# 通用栅格直排规范（grid-composition）

> **定位**：v4.0 起，纯栅格/低自由度页型**移出版式库**，由 AI 按本规范直排——不查版式决策表、不调版式函数。
> 依据：对标评估判定（LaySPA arXiv 2509.16891 / GeoSVG-RL arXiv 2605.25447）——AI 对纯栅格切分稳定，
> 对连接线锚点、象限落位、polygon 咬合不可靠；后者保留在版式库。
> **回退条款**：若某直排页型在实际生成中反复画错（栏宽不均、对齐漂移），恢复该版式骨架回库；
> 以真实使用频率 + 生成成功率**季度复核**（评估文档原建议）。

---

## 一、直排流程

1. 页面框架：标准 Chrome 调 `themes.chrome`（整页深色引言/宣言页免 chrome，用深底 + 极简页脚：来源左下 10px、页码右下 mono）。
2. 分栏坐标：**只查 `grid-system.md §三**（单栏 3.1 / 两栏 3.2 / 三栏 3.3 / 四栏 3.4 / 上下 3.5 / 上1下N 3.6 / 主从 3.7）——坐标单一事实源在 grid，本文件不复制数值。
3. 构件：标题/细线/bullet 层级/箭头/状态点用 `svg-skeleton-common.md` 构件与 `components.py` 原子；字号层级查 `brand-spec/tokens.css`。
4. 图占位一律 `components.placeholder(x, y, w, h, label)`，禁 AI 生成图与网图。
5. 产出走正常 lint 五项预检与转换链，纪律不因直排而豁免。

## 二、页型直排指引（原版式库移出项 · 结构要点与纪律收编）

> 版式退库，**纪律不退**。以下每条的纪律为硬要求，Phase 8 照常质检。

**大数字页**（原 I-01）：超大数字（mono，整页档 ≥107px）+ 断言句 + **对比锚点必填**（同比/目标/行业基准三选一，数字禁止悬空）+ 页脚来源必填。可带 ≤3 条支撑（右列或下行）。
**时间窗/倒计时**（原 I-05）：过去—现在—未来三节点单轴 + 当前节点红色 `#9E3D31` + 警示标题；**窗口数字保持墨色**（brand 禁染红绿）；窗口数须可复算（给基准日）。
**深色引言页**（原 T-01）：深底 `--ppt-surface-dark` + 左对齐大字 + 右下署名。**真实语录必须可考（人名+出处）；自撰声明句必须注明"本演示自撰"，禁止冒充名人语录**。
**白底宣言页**（原 T-02）：居中大字双行 + 短线 + 副注。宣言必须是**断言句**（有立场、可被反驳），不是主题词。
**章节承接页**（原 T-03）：左"刚讲完"（灰降调）/ 右"即将进入"（墨）双栏 + 底部进度。左右都必须是**内容概括**（讲了什么结论），不是章节名复读。
**轻量时间线**（原 S-03）：单轴 3–5 节点等距 + 节点卡；日期与事实须可考；"今日"标记用 `structures.flag_line`。多泳道/依赖 → 回库查 A-90。
**VS 对照**（原 S-08）：左灰右墨两列、**行行同一维度可比**、行数 3–5、中缝分隔；推荐侧固定右列。
**全版容器**（原 S-12）：面板 + 标题 + 分隔线 + 自由内容；遵守内容区红线 x 40–1240。
**三步行动卡**（原 A-01）：三栏卡、末卡深色收束；每步必须有**时间标注 + 可执行动词**。多步排期 → 回库查 A-90。
**A/B 选择**（原 A-02）：上下两横条（A 推荐墨条 / B 备选灰条降调）+ 各自 pros/cons（绿 `#5A7A60` / 绛 `#9E3D31`）；两选项必须互斥、推荐位固定 A。多阶段带概率 → 回库查 A-05 决策树。
**支柱并立**（原 G-02）：2–4 柱等距 + 柱内要点 + 底部深墨结论块；柱间必须**真并列**（同抽象度），每柱结论是判断句。
**三栏并列 / 两栏等分 / 主从三栏 / 左因右果 / 左图右文**（原 S-01/S-05/S-04/S-06/E-01）：按 grid §三对应分栏直排；因果页箭头仅单方向（line+polygon，禁 marker）；图文页**图占比 40–75%** 硬性区间。

## 三、何时回到版式库

内容命中以下任一特征时，**停止直排、回 `layout-library.md` 决策表**选版式：
定量落位（气泡/散点入象限）、树/分层对齐、泳道与依赖、流宽∝数值、polygon 咬合（金字塔/价值链）、
曲线路径（概念曲线/三地平线）、箭头链咬合（流程/雪佛龙）、表格式硬校验（RACI 每行一 A / 报价合计）、
评估梯度（Harvey Balls）、多阶段概率决策（决策树）、同构小图网格（small multiples）。
