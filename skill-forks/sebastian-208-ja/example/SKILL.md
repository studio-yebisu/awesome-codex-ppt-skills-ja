# 研究原稿から書式をそろえた画像スライドを作る

論文・研究報告・稿などを根拠に、Academic Input Packと頁ごとのBlueprintを整え、imagegenによる3案・アンカー・全頁画像を経て、文字・数値・図の原典忠実性を確認し、全面画像1枚と話者ノートを各頁へ包装する。

原典 [demoolight/academic-image-ppt](https://github.com/demoolight/academic-image-ppt/tree/2aac1a711ff658ab67d79a0e98cc54b5a0468751)、固定commit `2aac1a711ff658ab67d79a0e98cc54b5a0468751`、MIT。原典とLICENSEを保持した日本語派生で、公式翻訳ではない。

## 用意するもの

論文・研究報告・稿、発表条件、保持する主張・数値・図、参考画像や書式の希望。

- Node.jsとPptxGenJS4.0.1（source/package-lock.json）、Python3とPillow/python-pptx。
- 実描画にはWindows PowerPoint16、PDF→PNGにはpypdfium2。既存依存を使用し、新規installは未検証。
- 新規頁画像の制作にはbuilt-in image_gen。保存済み頁の再包装に画像生成・OCRは不要。

## 出力

各頁を全面画像1枚で収めたPPTX、話者ノート、元の頁画像。本文・図の個別編集には対応しない。

## 使い方

1. 最初に発表の目的・聴衆・時間・必要な資料や図を対話で揃え、Alignment Summaryをユーザーに示して確認を得る。確認前に制作方向を固定しない。
2. 原稿からAcademic Input Packと全頁Blueprintを作り、章・主張・根拠・正確なコピー・図の役割・ノートを対応させる。全頁計画をユーザーへ示し、承認後に3案へ進む。
3. image_genで原典形式の3案ボードを作り、ユーザーの選択と修正確認を記録する。採用ボードから配色・書体・図・密度など9項目のスタイル契約を固定する。
4. 採用契約から1〜2頁の実サンプルを生成して示し、品質と書式の継承についてユーザー承認を得る。必要な修正契約を作り、アンカーから残りの頁へ展開する。
5. 全頁の意味を持つ文字・数値・図と出典を照合する。原典package_image_pptx_with_notes.mjsで画像1枚と話者ノートを各頁へ包装し、頁数・画像・ノートと実表示を確認する。

## 今回の作例

**この自律作例では、目的合わせ・Blueprint・3案選択・実サンプルのユーザー承認ゲートを実演していない。現在の改善委任に基づく制作担当判断で進め、承認取得とは記録しない。**

架空の研究構想の稿から4部構成を計画し、採用Aの紙白・深紺と建築図の契約を11頁すべてへ適用した。6頁の構造図と1頁の表紙を先に確認し、残り9頁を新規生成。原典包装CLIで画像と話者ノートをPPTXへ収め、実PowerPointで全11頁を読んだ。

- **2頁：稿の4部を索引にする**：4行の視点03–04／空間05–06／体験07–08／検証09–10と短い説明を見る。稿から作った章立てと実際の頁範囲が一致し、下に未検証表記を残す。 原典Blueprintは内容から章・頁数を導き、目次と各章の構造を揃える。今回は稿に明記した4部を使う。
- **6頁：庇・席・棚の役割を図で説明**：右図の3本の引出線が屋根端・座面・水平な棚板を指す位置を見る。左の役割名に対応し、「概念図・寸法未設定」と未検証表記も残す。 原典はvisual opportunityとmust-preserve evidenceを頁ごとに定め、image_gen後にラベルと図の意味を検査する。
- **10頁：結果を作らず検証手順を示す**：試作・観察・見直しの3場面と対応文、下の「検証計画案／実施前」を読む。前の建築図と同じ片流れ庇・左席・右棚を使い、結果数値は加えない。 原典source-faithful契約は根拠のない数値・実験成果・引用を足さない。今回は計画であることを本文とノートに残す。

## 実施範囲と制約

4・8・10頁の挿絵内にあるノートの手書き風の線・擬似文字は装飾で、内容や研究証拠を持たない。正確な文として照合する対象は見出し・本文・図のラベル・数値・ページ番号である。

- 本文・図は画像で個別編集できない。ノートの編集と頁画像の差し替えに対応する。
- この作例は架空の研究構想の稿を使用。公刊論文の抽出、原論文グラフの厳密再描画、実測結果や施工・安全性の検証は未実施。
- 現在の11頁は稿と全頁Blueprintを凍結して新規生成した。旧版は現物の出力として混在させない。
- ボードA採用と実サンプル確認は、現在の自律改修指示に基づく制作担当判断。過去の個別ユーザー承認は未取得。
- 3案は実image_gen生成。各ボードの6枠の厳密な16:9比率は未計測。最終頁は原典既定の1280×720。
- 画像内の明朝／ゴシックは見え方の指定。実フォントの埋込・種類を証明するものではない。

原稿と生成時点はinput/data.jsonおよびsource/current-generation-map.json、検査はQA.json。過去の出力を現在版へ取り違えない。現在版の独立Kimi K3・Opus5.5再評価は未完了で、制作担当の目視と採点を混同しない。保存済み頁の再実行は[REPRODUCE.md](REPRODUCE.md)。
