# AIに任せる前の設計図

架空の実用例集。実在人物、私的会話、実績を使わない。

## 目的
日本語の制作依頼を、目的・読み手・入力・制約・完成条件に分けて書く方法を示す。対象は初めてAIへ文章や資料制作を頼む人。

## 7頁の構成
1. 表紙：AIに任せる前の設計図
2. 五つの問い：目的／読み手／入力／制約／完成条件
3. 目的・読み手：架空展示会の招待メール。来場候補日の返信、初めて来る近隣の店舗担当者、所要時間を明記。
4. 入力：新人向け搬入手順書。現行v3・場所の写真・確認済み注意事項を正本に。未確認の安全基準、個人連絡先、写真にない経路は作らない。
5. 制約：展示会告知ポスター。A3縦・印刷PDF。会期、会場、入場方法、問合せ。実績・来場者数・割引を作らない。赤黒白、見出し2行。
6. 完成条件：招待メールは必要情報、件名30字以内・本文300字以内、入力にない事実なし。不明点を列挙。人が送信前に日時・住所・返信先を確認。
7. 統合：目的・読み手・入力・制約・完成条件を一つの依頼に。送信せずレビュー用の一案を渡す。
