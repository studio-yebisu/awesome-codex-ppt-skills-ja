Usage: pptwise build [options] <target>

Assemble, validate, audit, preview and render a deck in one pass. Writes the
pages and, only when every check passes, the deck's one .pptx under
.pptwise/<deck>/ — exits 1 when the deck needs revision

Arguments:
  target             deck project directory or IR JSON file

Options:
  --json             print the full report: status, every problem with its page,
                     file and field, which pages the theme's signature layouts
                     drew and the nearest recipe for the rest, the preview, and
                     the .pptx path
  --no-git-ignore    do not write .pptwise/.gitignore or add .pptwise/ to this
                     repository's local exclude file
  --alternatives     also draw the deck's cover and one or two content pages in
                     up to 3 other themes, under .pptwise/<deck>/alternatives/
                     (done once by default, on the first build of a deck on a
                     built-in theme)
  --no-alternatives  do not draw the deck in other themes, even on its first
                     build
  -h, --help         display help for command

Example:
  $ pptwise build my-deck/ --json
