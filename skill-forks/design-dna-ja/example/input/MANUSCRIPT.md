# 町の道具を、借り合う。

読者: 地域で小さな道具棚の運用案を話し合うメンバー。
架空の企画です。参加者数・効果・費用・日時・会場は未確定。安全性や運用効果を実証したとは述べません。

1. 町の道具を、借り合う。
   使う日だけ、ひとつ借りる。参考画像の紙・墨・三原色・大きい和文を、新しい道具棚の案へ適用する。
2. 借りる道具は、使い道で選ぶ。
   台車: 道具を運ぶとき。小さな机: 机上を使うとき。椅子: 腰を落ち着けるとき。
   図は自作の簡略説明図。製品の仕様や耐荷重を示すものではない。
3. 棚の担当を、三つの役に。
   受付: 予定と道具を確認する。
   点検: 戻った状態を記録する。
   相談: 破損や遅れの窓口になる。
   人数や具体的な当番表は未定。
4. 借りる・使う・返すを、ひと続きに。
   借りる: 受取日時と返却予定を確認。
   使う: 予定した場所で使い、気になる状態は相談。
   返す: 棚の担当と一緒に状態を確認。
   運用の提案であり、安全性を保証する手順の実証ではない。
5. 予定と状態を、同じ表で見る。
   説明用の仮の状態表。実際の貸出記録や予定ではない。
   台車 / A / 貸出中 / 返却を待つ。
   小さな机 / B / 空き / 受取日時を決める。
   椅子 / 予約なし / 確認中 / 点検後に案内する。
6. まずは、棚の担当へ。
   借りたい道具と使う日を伝える。返すときは状態も一緒に。
   気になることは使う前に相談を。
   日時・会場・費用・参加者数は未定。安全性・運用効果は未検証。
