01 / 素材と主張

教材の入口は「学習後に何ができるか」

架空の教材テーマスマホ撮影で、被写体に合う光を選べる

動画例「窓際で撮る、商品写真の基本」を教材化する。

素材を確認する動画、字幕、実演カットを照合。権利と公開範囲を記録する。
主張を一文にする「光の方向で、形の見え方が変わる」。実演で説明できる範囲に絞る。
到達点を決める学習者が新しい被写体でも光の方向を選び、理由を説明する。

02 / チャプター

章は話した順序より、判断の順序で組む

学習の章素材の役割学習者の行動編集の判断
光を見つける窓と被写体の位置を示す実演光が来る方向を指す位置関係が見えるカットを残す
見え方を比べる正面光と側面光の比較影と輪郭の違いを説明する同じ被写体・条件の比較を並べる
目的に合わせる立体感を出す選択の解説撮影の目的から光を選ぶ選択理由を字幕で補う
自分で試す別の被写体への応用撮影し、選択を振り返る課題と確認観点を渡す
章ごとに、到達点へつながる「一つの行動」を置く。

04 / 図解

図解の型は、説明する関係で選ぶ

何を理解して
ほしいか

05 / 小テスト

小テストは、章の到達点と同じ行動を問う

設問例凹凸を見せたい同じ被写体を、正面光と側面光で撮った。どちらを選ぶ？
回答と理由側面光を選ぶこの実演条件では、横からの光で影が生まれ、凹凸が見えやすい。選択と理由をセットで答える。
確認と再学習比較の章へ戻る影の違いが分からなければ、同じ条件の比較カットを見直す。

架空の設問例。教材の実演条件に合わせて正答・例外を確認する。

動画一本を、教材へ。 / 07
06 / 再利用

再利用の前に、教材部品の根拠と権利を確かめる

公開前の確認残す記録通過条件未確認の場合
主張と素材の対応元動画の位置・字幕・章ID説明の文脈が一致する原典に戻って修正
図解と小テストの整合到達点・正答・解説教えた判断を問う設問を組み直す
利用権と公開範囲制作者・許諾範囲・素材の出典配布先に必要な権利がある該当素材を外す
版と更新責任教材の版・変更理由・更新担当差替え先を追跡できる配布を保留する
次の一歩：一章だけ試作し、学習者が選択理由を説明できるか確かめる。

架空・未実施の企画例。学習効果、制作時間、収益の実績は示していません。
