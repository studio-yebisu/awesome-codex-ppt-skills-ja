# Outline

Thesis: 朝の選択と準備を前夜へ移し、朝の短縮と一日の負担を両方測る。
Audience: 本人・家族。
Closing: 実績を記録して継続・変更を決める。

1. 朝に、余白を。
   朝の支度を急ぐのではなく、前夜へ選択と準備を移す企画です。40分から30分という目標は仮定で、短縮効果の実績はありません。
2. 10分を、前夜へ移す。
   服を選ぶ4分、鍵を探す3分、バッグを詰める3分を短縮候補と仮定します。合計10分ですが、各値は測定結果ではありません。
3. 前夜に、3つだけ。
   前夜の準備は服・鍵・バッグの3つに限定します。カードの内容が次のページへ移動し、夜と朝の役割分担につながります。
4. 朝は、確認して出る。
   夜は選ぶ・置く・詰める、朝は確認する役割に分けます。朝だけでなく、前夜に増えた準備時間も必ず記録し、合計負担が増えていないか確認します。
5. 5日間、測って決める。
   5日間、起床から出発までの時間と前夜の準備時間、忘れ物、負担感を記録します。記録はまだありません。朝の短縮と一日の負担の両方を見て継続・変更を決めます。
