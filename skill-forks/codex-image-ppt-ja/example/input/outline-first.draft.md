# 自分の原稿から作る構成の最小例（未実行草案）

読者：会議資料を初めて共有する社内メンバー
目的：共有前に確かめる項目を伝える
原稿：ファイルの版、共有先、参照元の3点を確かめる。

## Slide 1: 共有前に確かめる3点

- 要点：ファイルが渡したい版か確かめる。
- 要点：共有先と閲覧できる人を確かめる。
- 要点：数字・引用の参照元を確かめる。
- 役割：手順を説明する内容頁。書式確認後の見本候補。
- 図の案：3つの確認項目を順番に配置する。
- 必須の原図：なし。画像・表を追加する場合は出典と役割を先に指定する。

画像生成・見本採用・人間承認は行っていない。自分の原稿へ置き換えて構成を確認してから次へ進む。
