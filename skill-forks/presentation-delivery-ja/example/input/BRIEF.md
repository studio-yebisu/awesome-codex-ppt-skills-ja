# 制作条件

社内で資料を引き継ぐ人へ、次の人が動ける案内の作り方を日本語6枚で説明する。架空のファイル名と作業状況の例は記入例と明示する。既存カタログの紙色・深緑を参考に、BIZ UDPGothicの太字と本文を組む。

原典のPath A（HTML先行・960×540pt）、deck_index.htmlの原典概覧、原典html2pptx.jsの検査・要素変換、原典PDF結合を使う。内容は資料の引き継ぎの説明で、カタログやスキル自体の宣伝ではない。

## 制作判断

- 読み手：社内で資料を渡す人。画面共有・PC閲覧を想定。
- 目的：用途・保存先・次の行動がそろった引き継ぎにする。
- 題材固有の形：資料→確認→次の行動の連なりと、完了／保留の対照。
- 原典の質問工程は、ユーザーの実装委任に基づき制作側の仮定を記録して進める。人の早期承認・正式採用とは扱わない。
- 実在の製品名、ブランド、実績の数値、装飾写真は使わない。既存の明示された設計文脈があるため3案のFallback工程は未実施。
- 最初に封面と完了／保留の2枚を制作・表示確認し、残りを制作する。
