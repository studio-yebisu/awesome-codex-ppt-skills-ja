# CyberPPTの一般手順と同梱例

一般の3段階と確認門は上位SKILL.md、全文はupstream/SKILL.mdと5参照に保持する。固定8画像をupstream/assets/palette-samplesへ復旧したが、今回の作例で利用者が選んだ実績とはしない。

同梱例は保存済みImageGen原図5頁からのStage3技術部分。再生成はexample/source/reproduce.py、必要依存と表示はexample/REPRODUCE.md。座標の固定コードはその5原図だけに使う。新題材では元資料から内容を固定し、実画像生成、当該原図の新しい要素/座標/署名が必要。

原典のpixel/bboxと全指定strictを実行して不合格を保持する。日本語の文字枠・改行・脚注余白を改善しても元の合格条件を変えない。人間の段階/逐頁承認は捏造しない。旧source/finalize.pyは初期カタログ生成の保存であり現版の入口ではない。

元MIT原文・著作権・取得固定commitを保持する。OS字体は配布しない。
