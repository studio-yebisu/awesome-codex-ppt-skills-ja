# 話し合いの進め方 — 手描き章扉

章の話題を、意味に合う手描き図と短い章題で区切る作例です。表紙＋「気づきを集める／意見を共有する／小さく試す／結果を記録する」の5頁。架空のワークショップ用で、活動の実績・改善効果を示す資料ではありません。

原典のPptxGenJS＋sharp雛形、低彩度の寒暖色、左下の章題40pt regular、Calibri14ptの章ラベルと右下番号を適用。章の4点は原典SVG#1/#2/#20/#23を未改変でPNG化しています。表紙は大きな図を置かず、小さな派生sparkleだけです。旧版の赤枠や大きな苗木は撤去しました。

**日本語の書体は派生です。** 欧文Georgiaを保持し、日本語グリフだけOOXMLのa:eaでYu Minchoを指定します。実際のPowerPoint PDFにはYuMincho-RegularとCalibriを確認しました。字体ファイルは再配布も埋込みもしません。章題と番号は個別編集できます。図の線はPNGなので個別編集できません。

原典Step6のLibreOffice PDF→全5JPEG150dpi、およびPowerPoint PDF→全5PNGを実見しました。文字切れ・重なり・図位置・色・番号を確認。2頁の章題だけを別コピーで変更、保存後に開き直して画像化しました。確認結果はQA.json、reviews/page-audit.jsonへ記録。独立モデル採点や人間の採用とは別です。

再実行はREPRODUCE.md、汎用の使い方はSKILL.md。原典の固定commit・MIT・SVG原文はupstream/、PptxGenJS/sharpの条件はdependency-licenses/を参照してください。依存バイナリ・node_modulesはZIPへ含めません。

作例一式はexample/にあります。
