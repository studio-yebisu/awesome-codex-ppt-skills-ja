# Content Planning

Use content planning to turn arbitrary input into a slide-ready structure.

## content_plan.md

Include:

- User goal
- Audience
- Context and use case
- Core message
- Narrative arc
- Sections
- Source material map
- Facts or data that must not change
- Assumptions
- Open questions

## slides_plan.json

Each slide needs:

- `slide_id`
- `title`
- `purpose`
- `slide_type`
- `layout_family`
- `content_budget`
- `assets`
- `speaker_notes_seed`
- `qa_risks`

## Slide Types

Use a small stable set:

- cover
- toc
- section_divider
- content
- comparison
- data
- process
- timeline
- case
- summary
- closing

## Content Budget

Every content slide must have explicit limits:

- max words
- max cards
- max bullets
- max chart density
- whether speaker notes carry detail instead of slide text

When content exceeds budget, split into more slides or move detail into speaker notes.
