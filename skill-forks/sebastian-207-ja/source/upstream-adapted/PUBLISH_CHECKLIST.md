# Publish Checklist

Before pushing to GitHub:

- [x] Skill folder contains `SKILL.md`.
- [x] Skill has `agents/openai.yaml`.
- [x] Runtime folders are excluded.
- [x] User source files are excluded.
- [x] No `.env`, private key, or API key file is included.
- [x] Python and Node dependency manifests are included.
- [x] Root README explains install and usage.
- [ ] Create an empty GitHub repository.
- [ ] Add the GitHub remote URL.
- [ ] Push the local `main` branch.

Suggested GitHub repository name:

```text
codex-ppt-skill
```

Suggested description:

```text
A Codex skill for creating, editing, exporting, and QA-checking PowerPoint presentations.
```
