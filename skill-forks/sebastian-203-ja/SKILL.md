# 研究計画を仮説・図・評価へ整理する

研究概要やレビューの章を並べるだけで終えず、問い・仮説・比較・評価の関係へ組み替える。出典と仮説を区別し、主要図の読み方を付けて学術テンプレートへ配置する。

研究概要を背景・空間モデル・仮説・比較条件・調査・評価・制約へ組み替え、主要図に読図注記を付けた。結果を補作せず、仮説と計画を表示する。

原典は [ficooooo/Paper2ScholarSlides](https://github.com/ficooooo/Paper2ScholarSlides/tree/207f2b6c8493c569f6caf466c87d868c42936cf6)、固定 commit `207f2b6c8493c569f6caf466c87d868c42936cf6`。日本語派生であり公式翻訳ではない。

## 用意するもの

- Python / python-pptx、原典テンプレートを含む一式ZIP。
- 公式BIZ UDPGothicとPowerPoint等の実描画環境。PDF由来RGBプレビューにはpypdfium2。

## 使い方

1. 原稿とテンプレートの優先順位、事実・仮説・計画を確認する。
2. 主張と出典の対応を作り、問いから評価までを構成する。
3. 重要図の読図注記と未確認の条件を入れ、テンプレートを保持して生成する。
4. 原典の禁止語スキャンと全頁の実画像を確認し、修正後に再検査する。

## この作例で確認する箇所

- **2頁・図の読み方**：左の利用目的と右の席の希望、下段の「分類は設計仮説」を読む。 技術的な対象の対応を図で示し、主要図へ読み方と仮説の範囲を添える。
- **4頁・仮説の関係**：左右の矢印と「検証候補」、下段の交絡候補・読図注記を確認する。 仮説を実証済みの因果関係として描かず、関係の向きと読図上の制約を示す。
- **5頁・同じ基準で比較**：ゾーン境界・案内表示・検証したい点の3行で案A/Bを比べ、下部の設定条件を読む。 比較対象を同じ評価軸へそろえ、条件未確定の数値や結果を作らない。

## 適用範囲と未実施
