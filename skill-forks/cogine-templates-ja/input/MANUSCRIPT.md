# 6枚の原稿

1. **香りを、贈る。** 茶葉を選び、包みを整え、ひと言を添える。架空の茶の贈りもの企画。
2. **相手のひと息を、思い浮かべる。** いつ飲むか、どんな香りが好きか、どう淹れるかを聞いてみる。好みが不明なら尋ねてから選ぶ。
3. **包みを、整える。** 茶葉・包み・結びの説明用図形を、原典の三つの画像枠へ配置する。
4. **短い言葉を、ひとつ。** 「おつかれさま。ひと息つくときに、どうぞ。」添える言葉の例。
5. **選ぶ。包む。渡す。** 茶葉は相手の好みと道具から、包みは渡す場面から、言葉は相手へ向けて短く。
6. **贈るのは、ひと息のきっかけ。** 架空の企画。商品仕様・価格・効能・売上実績は示さない。
