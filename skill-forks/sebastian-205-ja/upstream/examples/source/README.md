# Example source

This showcase is derived from the open-access PLOS ONE article:

> Nwosu L, Li X, Qian L, Kim S, Dong X. Calibrated bagging deep learning for
> image semantic segmentation: A case study on COVID-19 chest X-ray image.
> PLOS ONE. 2022;17(11):e0276250.
> https://doi.org/10.1371/journal.pone.0276250

The article, full text, and figures are distributed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The PPTX preserves
the paper's figure labels and credits Nwosu et al. (2022), PLOS ONE, DOI
10.1371/journal.pone.0276250 on every result slide that uses or reconstructs
evidence from the article.

## Reproduce the source inputs

- Article: https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0276250
- Printable PDF: https://journals.plos.org/plosone/article/file?id=10.1371/journal.pone.0276250&type=printable
- JATS XML: https://journals.plos.org/plosone/article/file?id=10.1371/journal.pone.0276250&type=manuscript
- Figure images: use the `url` values in `paper-metadata.json`.

The source PDF, XML, and original figure files are intentionally not committed.
They can be retrieved from the stable URLs above. The committed deck and
showcase images are adaptations with attribution under the same CC BY 4.0
terms. Source content was retrieved on 2026-07-15.
