# 三阶段提示词

提示词只执行当前阶段；进入条件由 `SKILL.md` 状态机和任务目录中的 `deck-spec.md` 决定。

## Prompt 1A：逐页内容稿与自检

```text
基于已确认的源材料、使用场景、受众和页数预期，按 references/content-outline.md 提炼一套可审阅的逐页内容稿。

要求：
1. 先写受众的核心问题、整套回答、关键论证与页间推进，避免直接搬运原文或机械套用固定目录。
2. 每个内容页写明问题/作用、标题、主要结论、支撑要点、证据与可定位来源、解释及适用边界。封面、过渡等页按作用简化，不强制字数、文字占比或要点数量。
3. 写出页面实际展示的完整文案、图表关系与数据/必现标签；可选讲稿单列，不能把支撑结论必需的证据与边界全放进讲稿。不得只输出标题表、抽象摘要或“配一张图”。
4. 不得虚构材料中没有的数据、案例、人物、机制或引语；区分材料事实、衍生计算、推断和建议，注明计算口径。来源不足时缩小结论、调整内容，必要信息列为阻塞项。
5. 按目标覆盖、页间推进、论证深度、事实与口径、可见内容完整、篇幅与待确认项进行语义自检，记录当前版本、判断依据和问题页；未通过先修正，不进入风格阶段。字段齐全或交付脚本通过不能证明内容深度。
6. 只输出内容稿、自检结果和待确认项，不生成风格图片，不决定用户尚未授权的内容。

写入 deck-spec.md 并通过自检后，单独展示整套叙事和每页实际内容、支撑与边界，不能仅发文件链接。按 SKILL.md 状态表判断下一步：没有内容确认或对应代定授权时停止；已获授权时记录原文、范围与版本后继续。结合上下文识别已有授权，不要求固定口令。内容修改后复核受影响项。
```

## Prompt 1B：四套幻灯片浏览视图

```text
只使用 deck-spec.md 中已经自检通过、展示并获得确认或明确内容代定授权的逐页内容稿生成风格方案。

本次一次调用直接输出一套包含全部代表页的缩略图总览，不是逐页高清成品。四套分别调用一次，正常共四次。先选风格，再生成完整页面。仅总览排列或尺寸有误时，保存现有结果，用本地 build_style_overview.py 排版，不再调用生图处理缩放、网格、留白或外部页码。

总页数不超过 8 页时使用全部页面；超过 8 页时选择同一组 6–8 个覆盖主要页面类型的代表页。分别生成四张横向 16:9 的“幻灯片浏览视图”总览图，在中性底色上排列等大的完整缩略页，保留页间留白和外部页码，不能做纵向整页长图。3 页用 2×2 网格且留空一格，6 页用 3×2、8 页用 4×2；空位不补造页面。缩略页本身使用 deck-spec.md 的实际页面比例，不因总览画布为 16:9 而改变。总页数为 1 时，每套只含该页。

四套方案必须使用完全相同的页序、页面类型、标题、数字、核心内容和信息层级，只改变配色、字体气质、网格、版式系统、图形语言和素材风格。每张总览内部只能有一种统一风格。
布局要能承载已确定的正文、证据、解释及必要边界；缩略图不要求小字逐项可读，但不得以缩略展示为理由删掉正文区域或退化成“标题 + 大数字”。

多页任务不得用四张单页代替总览，不得把四套方案拼成一张四宫格，不得用纯文字风格说明代替图片。有参考但未锁定时，以参考的品牌约束为基础做四种不越界的演绎。

独立保存方案 1–4，并为每套写一句客观特点。不要继续生成完整页面。
重试和修正保持原方案编号，展示时说明替换的版本；最终候选只包含每套最新验收图，初稿与中间稿另存且不列为新增方案。
按 references/style-options.md 更新当前候选清单、执行结构检查并逐张视觉验收；未通过时修正对应方案，不宣布四套已完成。
```

## Prompt 2：完整图片版与 Page Spec

```text
根据已确认的逐页内容稿和锁定视觉规范，先建立符合 Page Spec v1 的 page-spec.json，再逐页生成完整的 16:9（或规格指定比例）PPT 页面图片。

Page Spec 对每页记录：
- 已确认内容版本、用户确认原文和风格决策授权；
- 稳定页面 ID、页码、标题和核心结论；
- 内容稿中全部页面展示文案、支撑要点、解释、必要边界、数字、表格/图表数据及来源；可选讲稿同步为 `speaker_notes`，不加入生图可见文案，不把工作记录当演讲备注；
- 图上必须清楚显示的数值、日期和单位填入 `required_visible_values`，不要把未绘出的底层图表数据误记为必现文字；
- 语义元素稳定 ID、确认状态、原生/图片意图和可选 bbox_hint；
- 页面视觉简报、图片文件、状态与实际生成提示词。

每一页生图提示必须重复提供：
1. `style.tokens` 中锁定的配色、实际字体和字号、网格、间距与图片处理，以及 `visual_spec` 中的图形语言、页码样式和禁用项；若有 `reference_images`，将对应图片作为可用的视觉参考输入；
2. Page Spec 中当前页的准确文字、数据、结论和来源约束；
3. 当前页页码和总页数；
4. 当前页允许出现的视觉对象、布局重点和独立素材意图。

要求：
- 一次只生成当前页，不自行增删页面或改写已确认内容。
- 文字、数字、日期和单位必须准确，不得乱码、错字、漏字、重复、裁切或溢出。
- 只绘制 Page Spec 声明的图表和数据关系；不得为装饰添加无来源的曲线、散点、坐标轴或趋势。研究设想使用带假设标记的流程/检验关系图。真实定量图的零轴、刻度、正负方向、条长/扇区比例必须符合源数据，不能只让数字标签正确。
- 不得为了美观删减关键事实或补充来源中没有的内容。
- 不得把已确认内容缩回“标题 + 大数字”，也不得临时编写未确认的分析正文。排不下时按变更流程调整表达或页数，更新内容稿并复核后继续。
- 跨页保持同一视觉系统，但版式服从内容，不机械复制同一网格。
- 文件按 01-title.png、02-title.png 的零填充格式保存。
- 验收失败只重做当前页，不连带重做已验收页面。
- 每页完成后把最终文件、状态、提示词和位置提示写回 Page Spec。

同一页文字连续两次仍不准确时，停止生图文字重试：按 Prompt 2A 生成保留全部主视觉的无字页面，再程序化叠加 Page Spec 中的准确文字，输出最终栅格页面。叠字前后按元素清单核对人物、产品、图形和插画仍完整；Step 2 的无字页面不等同于 Step 3 移除主体后的干净背景。

图表几何连续两次检查失败时停止同类生图修复，按[图表可靠性](chart-reliability.md)准备准确区域并遵守宿主程序改图授权；未解决不批准该页。检查整页有没有未声明的数据视觉，不能因所有已有标签匹配就跳过此项。
```

### Prompt 2A：无字背景兜底

```text
为 {画布} 演示文稿生成当前页的无字视觉背景。
严格沿用 {锁定视觉规范}，保留 {不可移动的背景内容} 和准确的信息留白。
移除标题、正文、数字、数据标签和页码，为程序化叠字留空。
保留 Page Spec 中全部非文字主体、图形和数据标记，包括 separate_asset 为 true 的人物、产品或插画；该标记仅要求 Step 3 将它们独立拆出。
不新增装饰，不改变已确认布局。
```

## Prompt 3：Page Spec 驱动的可编辑还原

```text
以 page-spec.json 为语义事实源、指定页面图片为视觉事实源，还原 Scene v1 并编译可编辑 PPTX。保持页序、比例、内容、排版、视觉重心和遮挡关系，不重新设计。

每次只处理 1–3 页：
1. 直接复用 Page Spec 中已确认/来源可验证的页面与元素 ID、文字、数据、来源、`speaker_notes` 和原生/图片意图，不重新 OCR 或改写这些内容；只对 `unresolved` 项继续核验。编译传 `--page-spec` 核对页序与讲稿。
2. 从页面图片补齐精确坐标、层级、样式、图片主体、背景和遮挡；记录来源与置信度。
3. 按 deck-spec.md 的基准图版本与变更记录核对差异：重建后已获授权的修改使用当前 Page Spec，仅对未记录或超出授权的冲突请求确认，不静默覆盖任一方。
4. 标题、正文、数字、页码、简单形状/线、表格和有可靠数据的图表使用原生对象。
5. 照片、人物、产品和复杂插画作为独立图片对象；separate_asset 为 true 的对象必须单独交付。
6. 从背景移除所有原生化文字与独立主体，只补全露出的背景。所有编辑从原始基准页开始，不串联编辑上一轮结果。
7. 原始整页图片只用于比对，不得充当可编辑版底图。
8. 复杂插画内部仍是像素；被遮挡区域若由 AI 补全，明确记录范围。

完成每批后编译、审查并渲染。只修有问题的 Scene 元素或素材，保留其他稳定 ID、页序、样式和层级。
```

### Prompt 3A：独立主体

```text
以 {原始基准页} 为唯一参考，提取或重建 Page Spec 中的 {元素 ID 与主体描述}。
保持身份、姿态、颜色、比例、光照和原始画布位置。输出真正带 alpha 的透明 PNG，只保留该主体及归属它的阴影/效果。
保持原画布尺寸；不得自动紧贴裁边，不添加文字、底板、棋盘格或其他对象。遮挡处只做最小补全并记录。
```

### Prompt 3B：背景清理

```text
以 {原始基准页} 为参考，从背景移除 {全部原生化元素和独立主体 ID 清单}。
只补全移除后露出的背景，保持其余结构、纹理、光照、尺寸、颜色和留白。
不得重排布局、移动剩余对象、改写文字或新增内容。
```

### Prompt 3C：局部修改

```text
只修改 {slide-id}/{element-id} 的 {文字/颜色/几何/图表数据/素材}。
先按 references/workflow-updates.md 保存基准版本和授权差异，再同步 page-spec.json、scene.json 或对应素材，保留其他对象 ID、页序、样式和层级。
仅修改可编辑版时保持 S6：文字、几何或数据修改不重新生图；图片内容变化只重做对应素材。将受影响原图片标为 revision，保留它作历史视觉基准，不将其作为最新图片版交付。重新编译、审查并渲染受影响页面。
用户同时要求更新图片版时，从更新后的可编辑 PPTX 渲染对应页面，重新验收并更新 Page Spec 后再导出图片版。
```
