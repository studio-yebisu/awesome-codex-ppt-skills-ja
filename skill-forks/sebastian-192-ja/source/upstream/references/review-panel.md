# 本地逐页审阅面板

从 2.14.0 起，默认流水线在完成渲染后生成 `review-panel.html`，并在 `summary.md` 中给出入口。面板内嵌当前源图片与渲染图片、逐页待办及规格内容；可离线打开，无网络请求或服务依赖。包含任务材料，转交时按原材料的分享范围处理。

面板是可选入口，不要求最终用户亲手填写。用户或实际查看画面的宿主 Agent 都可以记录审阅；Agent 也可直接填写原有 JSON 证据，再运行评分。面板用于方便复核和保留检查记录，不自动证明画面正确，也不新增用户必填步骤。

按页查看源图片与 PPTX 渲染；需要查看小字时点击“放大查看”。填写以下记录：

- 视觉状态及实际核对说明：布局、换行、裁切、比例和参考图差异。
- 实际数据视觉清单：填写实际看到的图表/表格 ID；无数据图也需核对并说明。额外数据视觉应记录失败，不把规格 ID 自动当作实际观察结果。
- 各数据对象的来源/数值、标签/单位、图表尺度/几何或表格行列对应；每个分项单独选择。页面视觉通过不能使这些分项自动通过。
- 源图片文字观测：实际看图后填写可见文字，再选择 partial/complete。规格内容仅供对照，不自动复制为观测。当前 PPTX 文字仍需在视觉项中核验。

面板默认沿用当前已记录的状态，待审项保持待审；没有“全部通过”按钮。下载记录可保留未完成项，但通过/失败须填写核对说明。进度表示填写程度，不代表评分通过。

## 保存与导入

点击“下载审阅记录”下载 `slidemuse-review-record.json`。编辑只保存在当前页面内，刷新/离开前下载；可用“载入已下载记录”恢复与同一面板快照绑定的草稿。面板不直接写本地证据文件。

导出后会保留“保存审阅记录文件”链接；若浏览器不支持下载，可展开并复制完整记录文本，保存为 UTF-8 JSON 后导入。导出提示只表示已生成记录，请确认文件实际保存成功。

```sh
python scripts/review_panel.py task/job.json task-output --import-record downloads/slidemuse-review-record.json
python scripts/run_deck.py task/job.json task-output
```

导入严格检查当前任务、Page Spec、Scene、素材、实际导出与渲染、原有记录和流水线状态。文件改变、页面重排、并发修改记录或修改绑定字段时拒绝导入，不覆盖已有记录；重新运行原任务并打开新面板后，实际复查再填写。载入旧面板草稿本身不能证明磁盘文件仍然有效，最终以导入检查为准。

已导入记录进入“待重新评分”，旧评分归档；重复原运行命令才计算当前交付结果。导入允许记录失败或未完成，不把 import 成功当作交付成功。两个证据文件使用带校验的导入日志提交，中断后下次运行先恢复完整提交；若期间输入或证据另有变化，保留文件并停止恢复。

生成后也可单独重建面板：

```sh
python scripts/review_panel.py task/job.json task-output
```

面板只支持流水线工作目录内的默认 `visual-review.json`、`content-observations.json`。任务显式提供外部视觉审阅或观测文件时，不生成可编辑面板，不写外部文件，继续按原配置提供证据。独立图表端点测量、可编辑对象检查、备注和数据依赖检查仍由原流程处理。

这是当前任务的静态快照，不是实时文件监视器。HTML 内嵌图片会增加文件体积；哈希不认证审阅者身份或原始事实，人工说明仍需真实核对。阶段耗时字段不包括面板生成和人工填写。
