# 制作依頼

日本語6枚「星を待つ、夜の天文台。」を、arifszn/slide-wright固定commit `d95ba204c9e98488b86b76ced75765ab4ec5de96`の原典テンプレートとエンジンで制作する。架空の観察イベント、日時/会場未定。天体観測実測や性能/科学データ、実施効果を作らない。

原典の「独自テーマ→実title/content2枚を同じ実ファイルで試作→最初に開く→その2枚を保持して残りをappend」を実施。1920×1080、背景sectionと内部frame、notes、inline CSS、stock themeを使わない契約を守る。CDN5.1.0の原典経路と必要ネット接続を保持する。

夜の青黒、明るいcyan、小さなamber。Dela Gothic Oneの大胆な和文見出し、Zen Kaku Gothic New本文、Space Grotesk英数字。公式の実字体/OFLを同梱しinline化。単一の観測の円/軌道deviceを各頁で変形し、説明用SVGを使う。4枚目は紙色、見る/話すの2列。硬いカード列を反復しない。

CSSの一斉entrance、少数のauto-animate、元engineのページ移動とreduce motionを使う。元engineへsame-origin 0-based yebisu-slide/page bridgeだけを追加して差分に残す。

現在のユーザー指定により内部デザインの判断・進行は承認済み。新たなpreview承認待ちは追加せず、派生変更として記録する。ユーザーの美術承認済みとは称さない。初回主要2枚表示と元engine稼働、必要生成だけを確認し、全6枚詳細検査・独立レビュー・構造監査・ZIP再実行は行わない。

完成HTML、代表2PNG、原稿/依頼、2枚からappendした記録、デザイン決定、原典未変更原本/局所差分、短い日本語SKILL、SOURCE、fonts/OFL、制作ZIPとfork ZIPを完成させる。
