# 指定した見た目

深青 #081629、電光青 #578aff、淡い珊瑚 #ffb5a5、明るいラベル #ecf2fc。原典kitはBYO stylesで色を強制しないので、presentation-local style.cssだけに指定。stable entityのtransform/opacityはlayoutIdを持つノードへ直接入れず、非layoutの子へopacityを指定する。

原典の固定880×380 canvasを保持、代表viewportは1600×900。単一BookWorld/共通groupKey、8つのtyped payloadで位置/サイズ/関係を変える。三つの節「置く／見つける／戻す」は元TOCのeraから生成。active TOC/progressを青/珊瑚で区別し、元attributionを読める色で保持。
