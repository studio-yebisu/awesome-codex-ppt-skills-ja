# 派生側の回避則

原典のlessons-learned.mdは変更せず、再利用できる用法の注意をここへ分ける。

- 番号と本文を空白だけで分けると測定・変換後に詰まる場合がある。意味のある改行か別の明示領域を使い、変換後に確認する。
- 単純なSVGの輪郭をnative化する専用処理を加える場合、対象形状と頂点を限定し、原典の汎用機能とは区別する。処理は構造/視覚検査より前に行う。
- HTMLのfont-weight数値とPowerPointのboldだけの表現を同じものと見なさない。配布字体・埋込状態・実PDFの字体を分け、比較の近くへ差を記す。
- 構造検査と変換成功だけを視覚的な合格とせず、安定した頁/要素名で指摘し、最小変更後に読み直す。
