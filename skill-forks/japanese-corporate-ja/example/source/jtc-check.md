# 原典の具体検査と残る判定

自己採点はしない。原典`jtc-authenticity.md`の17/20以上の受理は、現PPTXを読む独立評価で確認する。

- 2頁：前年/当月、万円、増加率とポイント差を同じ表に置く。粗利額380/432万円と差52万円を式で示す。
- 3頁：nativeチャートの系列・単位・期間は架空入力と一致。グラフ・注記・解釈・留意点・判断・含意が同時に読める。売上寄与から利益改善は推定しない。
- 4頁：現状と未確認の仮説、対応、目指す状態、対象範囲と移行条件を区別。
- 5頁：担当をまたぐ10関係をnative connector13線分で接続。記録名、判断ひし形、はい/不足の分岐、戻りを保持。『10/09の目標／分類率100%』は実績と分離。
- 6頁：native表に状況、条件、担当、期限、状態を併記。今回の着手案と次回の判断、未確認を分ける。同じ状態は同じ色と文字。
- 全頁：架空例と期間、出所、頁番号、主張、主図、含意を保持。全6実画像とcontactを視認し、184文字枠/表セルのoverflow0、package CRC、placeholder0を確認。母版/layout/themeの意味と編集可能部品を保持。表セルをPowerPointで編集→保存→再表示して確認。
- 修復前に3画像検索（結果0件）と公式6資料の実視認を行い、構成だけを反映。初回制作時の調査とは区別し、研究原図は公開物へ含めない。

未実施：現版の独立JTC17/20受理、現版の独立再評価、実業務の効果測定、利用者の採用、別PC/依存新規導入での互換検査。技術検査の成功だけを独立品質の合格としない。
